## Selected work

- **[LeakageLab — Temporal Risk Benchmark](https://github.com/VietAnh1803/LeakageLab)** — Independent, AI-assisted project using 50,000 synthetic transactions and delayed labels. Time-based validation selects the model; an ID-based grader checks submissions. The public CPU notebook writes 10,051 predictions with Internet off. All 18 tests passed locally; recorded author-side test AP is 0.1931. Synthetic results do not establish real-world performance. [Run on Kaggle](https://www.kaggle.com/code/vanh1803/leakagelab-public-reference-solver)
- **[Adult Income — Classical ML and PyTorch](https://github.com/VietAnh1803/HCMUT_ML_AdultCensusIncome_Pipeline)** — Compared models with training-only preprocessing and validation selection. LightGBM accuracy was 86.73% on 16,249 filtered, previously observed test records; MLP accuracy was 84.09–84.50% across three seeds. Added a public-validation scoring CLI and 50 automated tests, including checkpoint restoration. [Open in Colab](https://colab.research.google.com/github/VietAnh1803/HCMUT_ML_AdultCensusIncome_Pipeline/blob/main/notebooks/adult_income_improved.ipynb) · [Evaluation and limits](https://github.com/VietAnh1803/HCMUT_ML_AdultCensusIncome_Pipeline/blob/main/docs/verified_results.md)
- **[HealthMate](https://github.com/Brookvita3/HealthMate)** — Thesis with a team of three. I designed the Flutter interface and contributed to wearable stress-model and prescription-OCR evaluation. The thesis documents 15 WESAD participants, 869 windows and leave-one-subject-out validation; full-record per-subject normalization limits deployment interpretation. OCR comparison used 66 manually labeled prescriptions. [Flutter app](https://github.com/Btbach25/HealthMate_FE)
- **[Vietnam Stock Data Pipeline](https://github.com/VietAnh1803/Big-data-vnstock-pipeline)** — VNStock → Kafka → PySpark Structured Streaming → PostgreSQL/TimescaleDB, with incremental Snowflake sync, Bronze/Silver/DW modeling and Streams & Tasks. Streamlit/Plotly dashboards, Docker Compose, Nginx and Linux/systemd support operation. [System design](https://github.com/VietAnh1803/Big-data-vnstock-pipeline/blob/main/DOCS/SYSTEM_DESIGN.md)
- **[AI Content Impact Analysis](https://github.com/VietAnh1803/Data-Visualization-AI-Impact)** — Exploratory analysis and bilingual dashboard. The 200-row dataset has no documented sampling method, so the report avoids causal claims.

At OSAS via AI-MED, I contribute to insurance data warehousing, crawling and embedding pipelines for medical and financial-report assistants, and mobile UI/UX for the chatbot applications.
